# open-ps 路线图（ROADMAP）

> 状态：规划稿（Step 1）。产品范围见 [PRODUCT.md](./PRODUCT.md)，技术设计见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 原则

- **小步走**：每个 Step 一个（或少数几个）PR，可独立评审、可运行、不破坏上一步。
- 每个 Step 写明 **目标 / 范围 / 不做 / 验收标准**。超出范围的想法记到"后续候选"，不要顺手做。
- 从 Step 2 起，每个 PR 都必须通过 `lint`、`typecheck`、`test`、`build`。
- 产品或架构有变化时，先改 `PRODUCT.md` / `ARCHITECTURE.md`，再改代码。

## Step 2 — CS5 空壳 UI（仅界面，交给后续 UI 专项实现）

### 目标

搭出项目脚手架和一个**看起来、点起来都像 Photoshop CS5** 的静态外壳。所有菜单、工具、面板都在位，但**不做任何真实图像处理**。这一步的产出是后续所有 Step 的 UI 骨架。

### 范围（要做）

1. **脚手架**
   - Vite + Vue 3 + TypeScript（strict）+ Pinia；ESLint + Prettier + `vue-tsc`；Vitest。
   - `vite.config.ts` 设 `base: './'`。
   - `scripts/pack.mjs` + `npm run pack`：生成 `release/open-ps-<version>.zip`。
   - GitHub Actions：lint、typecheck、test、build。
   - 目录按 ARCHITECTURE §2 建立；本步只会实际用到 `src/main.ts`、`src/app/`、`src/ui/`、`src/lib/`，其余目录不要建空文件。
2. **主题**：`src/ui/theme/tokens.css` —— CS5 浅灰配色、中灰粘贴板、蓝色选中高亮、12px 中文字体栈；尺寸变量（菜单栏约 22px、选项栏约 32px、工具栏约 36px 宽、标签约 22px、状态栏约 22px、面板坞约 250px）。
3. **菜单栏**（`ui/shell/MenuBar.vue`）
   - 6 个菜单，文案、顺序、分隔线、快捷键显示**完全按 PRODUCT §6.1**。
   - CS5 菜单行为：点击打开；打开状态下鼠标移到相邻菜单自动切换；点击外部或 `Esc` 关闭；快捷键右对齐；禁用项置灰。
   - 菜单数据来自 `src/app/commands/` 命令注册表（ARCHITECTURE §7）。本步 `run()` 只做三件事之一：打开对应的空对话框、弹出"该功能将在后续版本提供"的提示、或什么都不做。
4. **工具选项栏**（`ui/shell/OptionsBar.vue`）：按当前工具显示 PRODUCT §6.2 中列出的选项控件（只有 UI 和本地状态，不影响任何东西）。
5. **左侧工具栏**（`ui/shell/Toolbar.vue`）
   - 10 个工具，顺序与图标按 PRODUCT §6.2；自绘 SVG 图标；悬停提示 `移动工具 (V)`。
   - 点击或按字母键（`KeyboardEvent.code`，忽略输入框与 IME）切换当前工具，高亮显示。
   - 底部单个前景色色块（默认黑色），点击打开拾色器对话框的**静态外观**（可选：仅能修改十六进制值）。`D` 复位为黑色。
6. **文档标签栏**（`ui/shell/DocumentTabs.vue`）：用 mock 数据显示 2 个标签，标题格式 `未命名-1 @ 100% (图层 1, RGB/8)`，可切换、可关闭（关闭只是从 mock 列表移除）。
7. **画布区**（`ui/canvas/CanvasHost.vue`）：粘贴板灰色背景 + 居中的白色矩形（代表画布，静态 DOM 或 canvas 均可，不做缩放平移）。屏蔽右键菜单与拖拽。
8. **状态栏**（`ui/shell/StatusBar.vue`）：缩放输入框（显示 100%，可编辑但无效果）+ `1920 × 1080 像素`。
9. **右侧图层面板**（`ui/panels/LayersPanel.vue`）
   - 布局按 PRODUCT §6.3：面板标签"图层"、"正常▼"（禁用）+ "不透明度"（可拖动标签调整数字）、图层行（眼睛 / 棋盘格缩略图占位 / 名称）、底部"创建新图层""删除图层"按钮。
   - 使用 mock 数据（例如"图层 2""文字 T""背景"三行）；允许：点击选中高亮、点眼睛切换、双击重命名、拖动排序、新建/删除——全部只改 mock 列表。
10. **对话框框架**（`ui/dialogs/Dialog.vue`）：CS5 风格（标题栏、右侧竖排"确定 / 取消"、可拖动、模态、`Enter`/`Esc`）。
    - 至少实现三个**静态表单**：新建、打开、导出（另存为）（字段按 PRODUCT §6.1；确定与取消都只是关闭）。其余对话框可留到对应 Step。
11. **shell store**（`src/app/stores/shell.ts`）：保存 mock 的标签、图层、当前工具、工具选项、前景色。文件头注明"mock，Step 3 由真实 Document 摘要替换"。
12. **文案**：全部来自 `src/app/strings.ts`。

### 不做（明确禁止）

- 不实现 `src/document/`、`src/canvas/`、`src/tools/`、`src/filters/`、`src/caf/`、`src/export/` 的任何逻辑。
- 不读写图片文件，不绘制像素，不实现缩放平移，不实现撤销重做。
- 不引入任何 UI 组件库、图标库、CSS 框架（Tailwind 也不要）。
- 不使用 Adobe 的图标或截图素材。

### 验收标准

- `npm run dev` 打开后，整体布局与 CS5 截图并排对比"一眼像"：菜单栏、选项栏、单列工具栏、标签页、粘贴板、右侧图层面板、状态栏位置正确。
- 6 个菜单的每一项文案和快捷键显示与 PRODUCT §6.1 逐字一致（有一个 Vitest 用例比对注册表与期望清单）。
- 10 个字母键都能切换工具，输入框中打字时不会切换。
- 新建 / 打开 / 导出 对话框可打开，`Enter`、`Esc`、拖动标题栏正常。
- 图层面板 mock 交互可用，外观接近 CS5。
- `npm run lint`、`typecheck`、`test`、`build`、`pack` 全部通过；`release/*.zip` 解压后用任意静态服务器打开可运行（相对路径正确）。
- 运行时依赖只有 `vue`、`pinia`。
- PR 附 1920×1080 下的整体截图。

## Step 3 — 文档模型 + 历史记录

- **目标**：建立 `src/document/`，让外壳接上真实数据。
- **范围**：`Layer`、`Surface`、`Document`、`History`、`Command` 及 `AddLayer` / `RemoveLayer` / `ReorderLayer` / `SetLayerProps` 命令；workspace store 持有 `markRaw` 的文档并发布摘要；"新建"对话框创建真实文档与标签；图层面板绑定真实图层（新建、删除、重排、显隐、不透明度、重命名）；`图层 › 新建图层`、`复制图层` 可用；编辑 › 撤销/重做 及快捷键可用，菜单显示"撤销 新建图层"；关闭未保存标签时确认；ESLint 依赖方向规则。
- **不做**：画布像素显示（仍是占位矩形，但尺寸比例随文档变化）、文件 IO。
- **验收**：`History` 与各命令单元测试覆盖撤销/重做/预算淘汰；面板操作全部可撤销；替换掉 Step 2 的 mock store。

## Step 4 — 视口与渲染

- **目标**：真正把文档画出来，并获得 CS5 平移缩放手感。
- **范围**：`Viewport`、`Compositor`（合成缓存 + 脏矩形）、`ViewRenderer`、overlay canvas；棋盘格；DPR 处理；PRODUCT §5.2 的全部平移缩放操作与档位；状态栏缩放输入；标签标题显示实时缩放比例；每个文档独立的视图状态。
- **不做**：任何绘画工具。
- **验收**：4000×3000 多图层文档平移缩放流畅；≥ 200% 像素清晰；`Ctrl+滚轮` / 捏合不会触发浏览器页面缩放；视口数学有单元测试。

## Step 5 — 打开与导出 + 首次 Toy 试打包

- **目标**：成为可用的看图/转格式工具，并尽早验证 Toy 平台约束。
- **范围**：打开对话框（拖放 + 选择文件 + 多选）、全窗口拖放打开、尺寸上限提示；导出对话框（格式、品质、预估大小、下载、iframe 降级）；`Ctrl+S` / `Shift+Ctrl+S`；导出后清 `dirty`；离开页面提醒。在 Toy 上传一次试用包，把核实到的限制回写到 PRODUCT §10。
- **验收**：PNG/JPEG/WebP 往返正确（含透明）；EXIF 方向正确；Toy 环境中能打开、导出（或走降级）。

## Step 6 — 选区核心 + 选择工具 M + 选择菜单

- **范围**：`Selection`（不可变 mask）与 `SetSelectionCommand`；`ToolManager` 与 `Tool` 接口、`CanvasHost` 指针事件转发；临时抓手（空格）；选择工具（四种模式与修饰键）；蚂蚁线；`取消选择`、`反选`、`扩展/缩小选区…`（形态学先在主线程实现，Step 11 移入 Worker 亦可）；`Delete` 清除、`Alt+Backspace` 前景色填充（`PixelPatchCommand` 首次落地）。
- **验收**：选区运算单元测试；所有选区变化可撤销。

## Step 7 — 智能填充迁移（CAF）

- **前置**：owner 提供仓库外备份的 PatchMatch Worker 源码。
- **范围**：按 ARCHITECTURE §10 迁入 `src/caf/`；`client.ts` 区域裁剪与回填；进度对话框（可取消）；`编辑 › 智能填充`、`Shift+F5` / `Shift+Backspace`；`tests/fixtures/caf/` 回归图与耗时记录；验证 Worker 在 Toy 包中能加载。
- **不做**：修改算法、引入 ONNX 或其他模型。
- **验收**：效果与仓库外验证版本一致；耗时不明显退化；取消后界面恢复且文档不变。

## Step 8 — 移动 V、画笔 B、吸管 I、拾色器

- **范围**：移动工具（图层偏移、选区内像素抬起、方向键微移）；画笔（盖印、笔触缓冲、硬度、不透明度、选区裁剪、`[` `]`、`Alt` 临时吸管、圆圈光标）；吸管（取样大小、样本）；CS5 风格拾色器完整功能。
- **验收**：快速画线无断点；一笔一步撤销；4000×3000 上绘画流畅。

## Step 9 — 魔棒 W、填充 G

- **范围**：扫描线洪水填充（连续/不连续、容差），大图走 Worker；魔棒四种选区模式；油漆桶前景色填充受选区限制。
- **验收**：洪水填充单元测试；8000×6000 图上魔棒不卡死界面。

## Step 10 — 图层菜单补全 + 图像菜单 + 裁剪 C

- **范围**：`向下合并`、`合并所有图层`（隐藏图层确认）、`复制图层到…`（含新建文档）；`画布大小…`（锚点、相对、扩展颜色）；`图像大小…`（约束比例、三种重采样，大比例缩小分步减半）；裁剪工具（手柄、压暗、`Enter`/`Esc`、选项栏提交/取消）。
- **验收**：各操作一步撤销；尺寸与偏移计算有单元测试。

## Step 11 — 特效：高斯模糊、锐化

- **范围**：`filters.worker.ts` 与 `client.ts`；高斯模糊（三次盒式近似、预乘 alpha）；锐化（USM）；对话框带预览（防抖、可视区域预览）；选区限制；进度与取消。
- **验收**：纯函数单元测试（固定输入输出）；大半径模糊时界面不卡。

## Step 12 — 文字 T + 栅格化

- **范围**：文字工具（放置、`<textarea>` 编辑、字体/字号/对齐/颜色、提交/取消、再编辑）；文字图层缩略图 "T"；像素操作前的栅格化确认（`requireRasterized`）；`图层 › 栅格化`。
- **验收**：文字图层可无损再编辑；合并/导出与普通图层一致；中文输入法下输入正常。

## Step 13 — 仿制 S

- **范围**：`Alt+点击` 取样、对齐/非对齐、复用画笔盖印框架、取样快照避免反馈。
- **验收**：与 PS 仿制图章行为一致的基本场景。

## Step 14 — 自由变换 v1

- **范围**：`编辑 › 自由变换`（`Alt+Ctrl+T`）；变换框 8 手柄 + 旋转；`Shift` 等比/15° 步进、`Alt` 以中心；有选区时抬起像素；`Enter` 高质量重采样提交、`Esc` 取消；文字图层先栅格化。
- **不做**：斜切、扭曲、透视、变形、数值输入。
- **验收**：一次变换一步撤销；多次变换不会累积模糊以外的错位。

## Step 15 — 钢笔 v1

- **范围**：直线锚点、闭合、`Backspace` 删点、`Enter`/`Ctrl+Enter` 转选区、`Esc` 放弃；数据结构预留贝塞尔控制柄字段。
- **不做**：贝塞尔曲线、路径面板。
- **验收**：路径转选区与选区模式组合正确。

## Step 16 — 打磨与 Toy 发布 v1.0

- **范围**：性能与内存（历史预算、大图上限实测并回写 PRODUCT §8.4）；快捷键全面核对（浏览器保留键、macOS、Toy iframe）；中文文案通读；Chrome / Edge / Firefox / Safari 冒烟；Playwright 端到端主流程；包体检查；`v1.0.0` 版本号与发布 zip。
- **验收**：PRODUCT 中 v1 清单全部达成；发布包在 Toy 正常运行。
