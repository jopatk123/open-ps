# open-ps 产品说明（PRODUCT）

> 状态：规划稿（Step 1）。本文件是产品范围的唯一依据；菜单、工具、快捷键的增删都应先改这里。
> 相关文档：[ARCHITECTURE.md](./ARCHITECTURE.md) · [ROADMAP.md](./ROADMAP.md)

## 1. 一句话定位

open-ps 是一个运行在浏览器里的轻量修图工具：**界面和手感像 Photoshop CS5，概念模型却尽量简单**。面向 B 站 Toy（以下简称 Toy）以静态包发布，界面为简体中文。

## 2. 产品目标

1. **CS5 手感**：平移/缩放、多文档标签页、左侧工具栏、右侧图层面板、顶部菜单与工具选项栏的布局和交互尽量贴近 Photoshop CS5，让老 PS 用户零学习成本。
2. **认知简单**：
   - 只有一种文档模型：一个文档 = 一组像素图层（从下到上叠加）+ 一个选区 + 一份历史记录。
   - 只有一种图层：**像素图层**。不区分 "图像图层 / 图形图层"（刻意避免 BitMappery 的 `LAYER_IMAGE` / `LAYER_GRAPHIC` 双类型）。文字图层只是"带有可编辑文字信息的像素图层"，栅格化后丢掉文字信息即可，详见 §6.3。
   - 只有一个**前景色**，没有前景/背景双色块，没有 X 交换。
   - 没有 PS 那种特殊的"背景"图层：新建白底文档时，底层只是一个名叫"背景"的普通图层，可移动、可透明、可删除。
3. **智能填充（内容识别填充）是核心卖点**：沿用已验证的 PatchMatch Worker（约 14KB，多尺度），对选区做 CS5 风格的 Content-Aware Fill。
4. **静态部署**：`vite build` 产出纯静态文件，打成 zip 上传 Toy；不依赖后端、不依赖外部 CDN。

## 3. 非目标（v1 明确不做）

- PSD 导入/导出；自有的分层工程文件格式（v1 只导出扁平图片，工程格式列入后续候选）。
- CMYK、16/32 位通道、色彩管理、打印分辨率（DPI）。
- 图层组、图层蒙版、调整图层、图层样式、智能对象、链接图层。
- 混合模式（v1 只有"正常"，下拉框可显示但禁用）。
- 背景色、色板面板、渐变工具、画笔预设库。
- 历史记录面板、动作、批处理、插件系统。
- 完整的贝塞尔钢笔（v1 只做直线段路径，见 §7）。
- 完整的自由变换（v1 只做移动 + 缩放 + 旋转，见 §7）。
- WebGL / WASM 渲染引擎、ONNX / AI 模型。智能填充只用现有 PatchMatch Worker。
- 用 Ant Design / Element / Material 等组件库"假装"PS 界面；外壳全部自绘。
- 账号、云存储、协作。
- 移动端/触屏优化（v1 以桌面浏览器为主，触屏只保证不崩）。
- 简体中文以外的语言（但文案集中管理，留出以后扩展的余地）。

## 4. 目标用户与使用场景

- 熟悉 PS 的 B 站用户，想在浏览器里快速：去水印/去杂物（智能填充）、裁图、调整尺寸、加字、简单涂抹、模糊/锐化、导出。
- 典型流程：**打开图片 → 魔棒/选择工具框选杂物 → 编辑 › 智能填充 → 裁剪 → 加文字 → 导出 PNG/JPEG**。

## 5. 界面布局（CS5 风格）

```
┌──────────────────────────────────────────────────────────────────────┐
│ 菜单栏：文件  编辑  图像  图层  选择  特效                            │
├──────────────────────────────────────────────────────────────────────┤
│ 工具选项栏：随当前工具变化（大小 / 容差 / 选区模式 / 字体 …）          │
├────┬──────────────────────────────────────────────┬──────────────────┤
│工具│ 文档标签：未命名-1 @ 100% (图层 1, RGB/8) ×  │ 图层面板          │
│ 栏 │──────────────────────────────────────────────│  正常▼ 不透明度   │
│ V  │                                              │  ◉ [缩略图] 图层2 │
│ M  │        灰色粘贴板（pasteboard）               │  ◉ [缩略图] 图层1 │
│ W  │          ┌──────────────┐                    │  ◉ [缩略图] 背景  │
│ C  │          │   画布        │                    │                  │
│ B  │          └──────────────┘                    │                  │
│ I  │                                              │                  │
│ P  │──────────────────────────────────────────────│                  │
│ S  │ 状态栏：100%  |  1920 × 1080 像素             │  [新建] [删除]    │
│ G  │                                              │                  │
│ T  │                                              │                  │
│ ■  │ ← 单个前景色色块                              │                  │
└────┴──────────────────────────────────────────────┴──────────────────┘
```

- **配色**：CS5 默认浅灰界面（不是 CS6 之后的深色），粘贴板为中灰色。具体色值在 Step 2 对照截图调校，作为 CSS 变量集中定义。不做深色主题。
- **字体**：UI 字号约 12px，字体栈 `"Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif`，不打包中文字体文件。
- **图标**：全部自绘 SVG，风格接近 CS5（单色灰、细线）。**不使用 Adobe 的图标、Logo 或商标素材。**
- **对话框**：CS5 风格——标题栏 + 左侧表单 + 右侧竖排"确定 / 取消"按钮；模态；Enter = 确定，Esc = 取消；可拖动。
- **最小窗口**：1280 × 720。低于此尺寸允许滚动，不做响应式重排。

### 5.1 多文档标签页

- 每个打开/新建的文档一个标签，标题格式与 CS5 一致：`文件名 @ 缩放% (当前图层名, RGB/8)`，有未导出修改时末尾加 `*`。
- 标签右侧 `×` 关闭；有未导出修改时弹窗确认（"是否放弃对"xxx"的修改？"）。
- 点击切换；每个文档有自己独立的缩放、平移、选区、历史记录和当前工具状态（工具本身全局共享）。
- 浏览器会拦截 `Ctrl+Tab` / `Ctrl+W`，因此**标签切换和关闭只靠鼠标**（见 §8.3）。
- 页面关闭/刷新时若有未导出文档，触发浏览器的离开确认。

### 5.2 平移与缩放（CS5 手感）

| 操作 | 行为 |
| --- | --- |
| 按住 `空格` + 拖动 | 临时抓手平移（松开空格回到原工具），光标变为抓手 |
| `Alt` + 滚轮 | 以鼠标位置为中心缩放（CS5 默认行为） |
| `Ctrl` + 滚轮 / 触控板双指捏合 | 同样以鼠标为中心缩放（并阻止浏览器页面缩放） |
| 滚轮 / `Shift` + 滚轮 | 垂直 / 水平滚动画布 |
| `Ctrl` + `=` 或 `Ctrl` + `+` | 放大到下一档 |
| `Ctrl` + `-` | 缩小到下一档 |
| `Ctrl` + `0` | 按屏幕大小缩放（适合窗口） |
| `Alt` + `Ctrl` + `0` | 实际像素 100%（CS5 原键位；`Ctrl+1` 被浏览器用于切换标签页，不使用） |
| 状态栏缩放输入框 | 直接输入百分比，回车生效 |

- 缩放档位沿用 PS 预设：6.25%、8.33%、12.5%、16.67%、25%、33.33%、50%、66.67%、100%、200%、300%、400%、500%、600%、700%、800%、1200%、1600%、3200%。
- 缩放 ≥ 200% 时最近邻显示（像素清晰可见）；< 100% 时平滑缩小。
- 平移有边界：画布不能被完全拖出视口。
- 新打开的文档默认"适合窗口"，但不超过 100%。
- 不提供 `Ctrl+空格` 点击放大：中文 Windows 上它是输入法切换键。

## 6. 功能清单

### 6.1 顶部菜单（仅以下 6 个，顺序固定）

快捷键一栏为 **open-ps 实际绑定**。括号内注明 PS 原生快捷键与差异原因。Windows 显示为 `Ctrl`，macOS 自动映射为 `⌘`。

#### 文件

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建… | `Alt+Ctrl+N`（PS 为 `Ctrl+N`，被浏览器保留） | 打开"新建"对话框：名称（默认"未命名-1"递增）、预设（自定义 / 1920×1080 / 1280×720 / 1080×1080 / 800×600）、宽度、高度（像素，1–8192）、背景内容（白色 / 透明 / 前景色）。确定后新开一个标签。 |
| 打开… | `Ctrl+O` | 打开"打开"对话框：拖放区 + "选择文件…"按钮，支持多选；格式 PNG / JPEG / WebP / GIF（首帧）/ BMP。每个文件新开一个标签，图片作为名为"背景"的图层。也支持把文件直接拖到窗口任意位置打开。 |
| 导出（另存为）… | `Shift+Ctrl+S`，`Ctrl+S` 同样打开此对话框 | 打开"导出"对话框：文件名、格式（PNG / JPEG / WebP）、品质滑杆（JPEG/WebP，0–100，默认 90）、预估文件大小。导出所有可见图层的合成结果；JPEG 透明区域以白色铺底。确定后触发下载。 |

#### 编辑

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| 撤销 | `Ctrl+Z` | 多级撤销（与 CS5 的 Ctrl+Z 单步切换不同，采用现代多级行为，更易理解）。菜单文字显示具体动作，如"撤销 画笔"。 |
| 重做 | `Shift+Ctrl+Z`、`Ctrl+Y` | 多级重做。 |
| 智能填充 | `Shift+F5`、`Shift+Backspace` | 对当前图层的选区执行内容识别填充（PatchMatch Worker）。无选区时禁用。执行时显示进度和"取消"按钮，界面不卡死；完成后为一步撤销。 |
| 自由变换 | `Alt+Ctrl+T`（PS 为 `Ctrl+T`，被浏览器保留） | 对当前图层（有选区时为选区内像素）显示变换框。v1：移动 + 缩放 + 旋转，见 §7。`Enter` 应用，`Esc` 取消。 |

#### 图像

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| 画布大小… | `Alt+Ctrl+C` | 对话框：当前尺寸、新宽度/高度（像素）、"相对"复选框、3×3 定位锚点、画布扩展颜色（透明 / 白色 / 前景色；非透明时只作用于最底层图层）。不缩放像素，只改画布范围。 |
| 图像大小… | `Alt+Ctrl+I` | 对话框：宽度/高度（像素或百分比）、"约束比例"（默认勾选，带链条图标）、重采样方式（两次立方（平滑）/ 两次线性 / 邻近（硬边缘））。缩放所有图层。 |

#### 图层

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| 复制图层 | `Ctrl+J` | 在当前图层上方复制整层，命名为"<原名> 副本"，不弹窗。 |
| 复制图层到… | — | 对话框：新图层名称、目标文档（当前已打开的文档列表 + "新建"）。选"新建"时用源文档尺寸新建文档并新开标签。图层保持原有位置偏移。 |

| --- | --- | --- |

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |

工具提示格式：`移动工具 (V)`。字母键切换工具（无修饰键时）。不做 PS 的同组工具 `Shift+字母` 循环。

### 6.3 图层面板（CS5 布局）

- 面板标题标签："图层"（v1 只有这一个面板，不做通道、路径、历史记录面板）。
- 顶部一行："正常 ▼"（混合模式，v1 禁用）+ "不透明度: 100% ▼"（输入框 + 弹出滑杆；可在"不透明度"文字上左右拖动快速调整，CS5 手感）。
- 图层列表（顶部为最上层），每行：眼睛图标（显示/隐藏）、棋盘格底的缩略图、图层名称。
  - 当前图层蓝底高亮；单击选中；双击名称重命名；拖动排序。
  - 文字图层的缩略图位置显示 "T" 图标。
- 底部按钮条：**创建新图层**、**删除图层**（只剩一个图层时禁用）。把图层拖到"创建新图层"按钮上 = 复制图层。
- 不做：多选图层、锁定、填充不透明度、链接、图层组、蒙版、样式。

**文字图层与栅格化**：文字图层始终持有一份渲染好的像素（参与合成、导出与普通图层完全一致），外加可再次编辑的文字信息（内容、字体、字号、颜色、对齐、位置）。对它使用画笔/仿制/填充/滤镜/智能填充/自由变换等像素操作时，先弹窗"此文字图层必须栅格化后才能继续。是否栅格化？"，确定则栅格化后继续。移动工具、不透明度、显隐、复制、重排不需要栅格化。

## 7. 分阶段 MVP 取舍

| 功能 | v1 做到 | 推迟到后续 |
| --- | --- | --- |
| 钢笔 | 直线段多边形路径 → 转选区；早期步骤可以只保留工具按钮（"即将推出"提示） | 贝塞尔曲线（拖出方向线）、锚点编辑、路径面板、描边路径 |
| 自由变换 | 移动 + 缩放（`Shift` 等比、`Alt` 以中心）+ 旋转（框外拖动，`Shift` 每 15°）；早期步骤菜单项可置灰 | 斜切、扭曲、透视、变形、数值输入、参考点移动 |
| 选择工具 | 矩形 | 椭圆（选项栏切换）、羽化、固定比例/固定大小 |
| 魔棒 | 当前图层、容差、连续 | 对所有图层取样、消除锯齿 |
| 仿制 | 当前图层取样、对齐 | 对所有图层取样、取样点叠加预览 |
| 画笔 | 圆形笔刷、大小/硬度/不透明度 | 流量、压感、笔刷形状 |
| 文字 | 横排、整段统一样式 | 竖排、逐字样式、段落文本框 |
| 裁剪 | 自由比例矩形 | 固定比例、旋转裁剪、透视裁剪 |
| 文件 | 打开图片、导出 PNG/JPEG/WebP | 分层工程文件（如 zip + JSON）、剪贴板粘贴 |

## 8. UX 约束

### 8.1 通用

- 任何超过约 200ms 的操作（智能填充、大半径模糊、大图缩放）必须在 Worker 中运行，显示进度，可取消，期间界面可操作（至少可取消、可平移查看）。
- 每个改变文档的操作都是一步可撤销的历史记录；选区变化也计入历史（与 PS 一致）。
- 所有像素操作作用于**当前图层**；有选区时被选区限制。
- 画布区域屏蔽浏览器默认行为：右键菜单、拖拽图片幽灵、文字选中、滚轮页面缩放、触控板捏合缩放。
- 快捷键在输入框、文字编辑中不触发（`Esc` / `Enter` 除外），中文输入法组字时（`isComposing`）一律忽略。
- 字母快捷键按物理键位（`KeyboardEvent.code`）识别，不受键盘布局和大小写影响。

### 8.2 补充交互（无菜单项，但保留 CS5 肌肉记忆）

| 按键 | 行为 |
| --- | --- |
| `Delete` / `Backspace` | 清除当前图层选区内像素为透明（无选区时无操作） |
| `Alt+Backspace` | 用前景色填充选区（无选区时填充整个图层） |
| `Enter` / `Esc` | 提交 / 取消当前进行中的裁剪、自由变换、钢笔路径、文字编辑 |
| `空格` 按住 | 临时抓手 |
| `[` `]` / `Shift+[` `Shift+]` | 画笔/仿制大小 / 硬度 |
| `D` | 前景色恢复为黑色 |
| 方向键 | 移动工具下微移 |

### 8.3 浏览器保留快捷键

Chrome / Edge / Firefox 不允许网页拦截：`Ctrl+N`、`Ctrl+Shift+N`、`Ctrl+T`、`Ctrl+Shift+T`、`Ctrl+W`、`Ctrl+Shift+W`、`Ctrl+Tab`、`Ctrl+PageUp/PageDown`、`Ctrl+1`～`Ctrl+9`（macOS 对应 `⌘`）。因此：

- 新建 → `Alt+Ctrl+N`；新建图层 → `Shift+Alt+Ctrl+N`；自由变换 → `Alt+Ctrl+T`。
- 标签切换与关闭只用鼠标。
- 以上替代键需在 Step 2 起的实际浏览器中逐一验证；如 Toy 内嵌环境另有冲突，以本节为准更新。

### 8.4 性能与容量

- 平移、缩放、画笔绘制在 4000×3000 文档上保持流畅（目标 60fps，最低 30fps）。
- 文档单边上限 8192px，总像素上限暂定 6400 万；超限时打开/新建/图像大小给出中文提示。具体数值在 Step 4 后实测校准。
- 历史记录按内存预算淘汰最旧步骤（预算默认约 512MB，可在代码中调整），不按固定步数。

## 9. 中文界面

- 所有可见文案为简体中文，术语尽量沿用 PS CS5 简体中文版（选区、图层、栅格化、容差、羽化、不透明度、画布大小、图像大小…）。例外：用户指定的名称优先（如"选择工具""特效""智能填充""导出（另存为）"）。
- 数字单位统一"像素"/"px"、"%"；尺寸写作 `1920 × 1080 像素`。
- 文案集中在一个模块中（菜单与命令注册表同源），禁止散落在组件里硬编码。
- 错误提示用中文且可操作，例如"图片过大（12000 × 9000 像素），最大支持 8192 像素。"。

## 10. Toy 打包与发布

- 产物：`vite build` 输出的 `dist/` 打包为 `open-ps-<版本号>.zip`，`index.html` 位于 zip 根目录。
- 所有资源路径为相对路径（`base: './'`），可部署在任意子路径。
- 零外部请求：不加载 CDN、字体、统计脚本；Worker 与图标都打进包内。
- 可能以 iframe 方式嵌入：键盘快捷键需要先点击画面获得焦点；下载可能受 iframe sandbox 限制——导出需有降级方案（在对话框中显示导出结果图片，提示"右键另存为"）。
- Toy 平台的具体限制（包体大小上限、入口文件名、iframe sandbox 属性、是否允许 module Worker）**尚未确认**，Step 5 做第一次试打包时核对并回写本节。
- 包体目标：首屏 JS + CSS（gzip 后）< 300KB，不含 Worker。

## 11. 智能填充（CAF）

- 用户流程：用选择/魔棒/钢笔建立选区 → `编辑 › 智能填充`（`Shift+F5`）→ 进度提示（可取消）→ 选区内被周围内容自然填补，一步撤销。
- 作用于当前图层（文字图层需先栅格化），只修改选区内像素。
- 算法：已验证的 PatchMatch Worker（约 14KB，多尺度）。**算法源码目前备份在仓库外，后续步骤迁入 `src/caf/`**；迁移时保持算法不变，只做协议适配。不引入 ONNX 或任何 AI 模型。
- 性能以现有验证版本为基线，迁移后不得明显退化。
